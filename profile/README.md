<h1 align="center">payfor工大</h1>
<p align="center">在食堂亮个付款码，回宿舍顺手查个电费。</p>

payfor工大是给合工大同学做的 Android 校园卡工具。打开手机就能出示校园付款码、查校园卡余额和宿舍费用。合肥和宣城校区能查的项目略有不同。

> [!NOTE]
> **首个公开版本正在准备中。** 源码和安装包发布后，下载入口会放在这里。

### 手机上怎么用

用校园卡账号登录，首页就能出示二维码和条形码。点校园费用卡片可以查明细，部分费用也能直接充值。用小米手环或带背屏的小米手机的同学，后续还可以按设备教程把付款码放到手环或背屏。

### 关于自动充值

自动充值是独立测试插件，会按你设定的条件实际扣减校园卡余额。把它单独提供，是为了让日常付款和查账不受测试影响。只建议能自行配置、排查问题、核对校方账单并愿意承担试用风险的人使用。

**这是个人维护的非官方项目，与合肥工业大学及校园服务提供方无关。** 涉及扣款或到账时，请以校方账单为准。
